## About me

I’m an **AI & Backend Engineer** focused on turning ambitious product ideas into dependable systems. I work across intelligent application layers, high-performance APIs, data infrastructure, and cloud delivery—with an emphasis on clean architecture, observable services, and software that remains easy to evolve.

- Building **LLM-powered features**, retrieval-augmented systems, tool-using workflows, and evaluation pipelines
- Designing **REST, GraphQL, and event-driven services** with strong authentication, caching, and background processing
- Engineering with **Python, FastAPI, Node.js, NestJS, TypeScript, and Go**
- Working across **PostgreSQL, MongoDB, Redis, vector search, and production data pipelines**
- Shipping on **AWS, Docker, Kubernetes, Linux, and GitHub Actions**
- Interested in open-source collaboration, distributed systems, AI reliability, and practical developer tooling
